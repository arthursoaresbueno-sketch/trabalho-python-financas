# App de Finanças

O programa permite:

- Registrar lançamentos de receitas e despesas;
- Visualizar o extrato de lançamentos;
- Gerar um relatório financeiro;
- Exportar o relatório para um arquivo de texto.

## Funcionalidades

1. Registrar lançamentos
2. Ver extrato
3. Relatório
4. Exportar relatório
5. Sair

## Tecnologias utilizadas

- Python 3
